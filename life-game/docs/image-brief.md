# 《人生之书》场景插画需求（给 Codex）

你好！这是一个手机网页小游戏《人生之书》：玩家走进一本线装书，从清晨 6 点出生，到第二天破晓，用 24 个小时过完一生。每个小时是一页，每页上方有一幅 4:3 的插画。现在这些画面是代码画的简笔画，需要你帮忙生成 **28 张插画**（24 张场景 + 4 张"之后"状态）。

请用你能用的图像生成工具（比如 gpt-image）逐张生成，按下面的规格保存。

---

## 一、交付规格

| 项目 | 要求 |
|---|---|
| 数量 | 28 张：24 张场景图 + 4 张 `-after` 图（见第四节） |
| 比例和尺寸 | 横图 **4:3**，最终导出 **1600×1200** 像素 |
| 格式 | **JPG**，质量 80 左右，每张尽量 **≤ 300KB**（手机流量） |
| 文件名 | 严格按第四节表格里的文件名，全部小写，比如 `rain.jpg`、`rain-after.jpg` |
| 存放位置 | 仓库里的 `life-game/public/scenes/` 目录 |

如果生成工具只能出别的尺寸（比如 1536×1024），请居中裁成 4:3 再缩放，例如：

```bash
magick input.png -resize 1600x1200^ -gravity center -extent 1600x1200 -strip -quality 80 rain.jpg
```

## 二、统一画风（每一张都要遵守）

**风格关键词**：新中式水墨淡彩插画，徽派白墙黛瓦的中国南方小城，2000 年代的日常生活，宣纸纹理，安静、怀旧、温暖、有人间烟火气。

**配色**：宣纸米白、黛青（深蓝灰）、石绿为主，**朱砂红只做点缀**（红伞、红灯笼、红书包这种小面积）。整体饱和度偏低，不要高饱和、不要霓虹、不要赛博朋克。

**光线随钟点变化**（每张图的钟点见第四节），这是整本书的节奏，请务必对上：

| 钟点 | 光线 |
|---|---|
| 05:00–07:00 | 破晓、清晨：粉金色、淡紫，柔和低角度阳光 |
| 08:00–14:00 | 白天：明亮、通透，天空淡蓝 |
| 15:00–17:00 | 午后到傍晚前：暖金色，影子拉长 |
| 18:00–19:00 | 黄昏：橘红晚霞，到紫色天空 |
| 20:00–04:00 | 深夜：黛蓝夜色，月亮、星星，室内是暖黄灯光 |

**必须遵守的规则**（这是游戏机制决定的，不是审美偏好）：

1. **不画任何文字**：没有招牌字、没有可读的纸面文字、没有水印、没有签名。纸张上的字用模糊的线条代替。
2. **人物不露正脸**：只画背影、侧后方、远景小人或者手。
   - 主角"你"可能是任何性别的玩家，**画成看不出性别的孩子或年轻人**：短发、朴素衣服、背影。
   - 带大主角的长辈，玩家可能选的是外婆、奶奶、外公、爷爷、妈妈或爸爸，所以**长辈也要看不出性别**：远景背影、灰白短发、朴素衣服，或者干脆只画手。
   - 唯一固定的人物是早餐摊的"王叔"（一位五六十岁的男摊主，系围裙），也只画侧后方或远景。
3. **右下角留空**：画面右下角大约 15% 的区域不要放重要内容，游戏会在那里叠一个圆形的小物件图标。
4. **不要画雨丝和大团热气**：雨和热气是游戏用代码叠上去的动态效果（会动）。下雨的那张只画"雨天的氛围"：湿漉漉的青石板、水洼、阴天。碗里冒热气可以画很淡的一点，不要画成浓雾。
5. **不出现**：现代品牌和商标、手机屏幕上的具体内容、血腥暴力、宗教符号、算命和占卜道具（罗盘、签筒、八卦图都不要）。

**反复出现的元素**（同一个东西前后要像同一个）：

- **家**：老房子里的一扇**圆形月洞窗**，窗边挂着一串**旧风铃**（铜色小管加一条红穗子），木质书桌，台灯。
- **巷口早餐摊**：红白条纹雨棚，竹蒸笼叠成一摞，油锅，蓝边白瓷碗。
- **主角的标志**：一个**红色书包**、一把**红色小伞**。

## 六、放进项目（如果你能改这个仓库）

1. 把 28 张 JPG（1600×1200）放进 `life-game/art/scenes-src/`。
2. 在 `life-game` 目录运行 `python3 scripts/optimize-scenes.py`（需要 `pip install pillow`）。它会生成：
   - `public/scenes/*.webp`：网页真正加载的图（约 85KB 一张，加载更快）
   - `src/scenes-lqip.json`：每张图的模糊占位图（翻到新一页时画面立刻出现，大图再淡入）
3. 确认 `src/config.ts` 里 `SCENE_IMAGES` 是 `true`，运行 `npm ci && npm test && npm run build`。
4. 提交并推送到 `claude/admiring-knuth-vw1v8f` 分支。

如果你不能改仓库，把 28 张图打包成一个 zip 发给我就行。缺了某一张也没关系，那一页会自动退回原来的代码画面，不会出现破图。谢谢！
