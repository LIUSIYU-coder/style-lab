# 免费部署到海外（先试水用）

用两样免费服务，全程 iPhone 就能完成，不需要命令行：

- **Render**：运行网站（免费实例）。
- **Upstash**：保存兑换码（免费 Redis）。Render 的免费实例休眠时会清空磁盘，所以兑换码不能存在它上面。

部署好以后，用网站自带的**管理页**（`/admin`）在手机上生成兑换码、查询、重置，不需要命令行。

> **先说清楚免费版的代价**
> - 15 分钟没人访问，网站就会休眠，下一个人打开要**等大约 1 分钟**。第 5 步的"定时唤醒"可以基本避免。
> - Render 的 `onrender.com` 域名在大陆能不能打开、速度如何，没有可靠的公开数据，**一定要按第 6 步实测**。
> - 适合录视频、给朋友试玩、小量卖。真正放量卖之前，建议换成 `docs/deploy.md` 里的香港服务器（兑换码存在 Upstash 里，搬家时不会丢）。

---

## 1. 建一个 Upstash 数据库（存兑换码）

1. 打开 upstash.com，用 GitHub 或 Google 账号登录。
2. 点 **Create Database**，类型选 **Redis**。名字随便填（比如 `life-book`），地区选 **Singapore（新加坡）**，套餐选 **Free**。
3. 建好后进入这个数据库，往下找到 **REST API** 一栏，复制两样东西，先存到备忘录里：
   - `UPSTASH_REDIS_REST_URL`（以 `https://` 开头）
   - `UPSTASH_REDIS_REST_TOKEN`（一长串字母）

## 2. 在 Render 上部署网站

1. 打开 render.com，用 **GitHub 账号**登录，按提示授权 Render 读取 `liusiyu-coder/style-lab` 这个仓库。
2. 点右上角 **New** → **Blueprint**。
3. 选择 `style-lab` 仓库，分支选 **`claude/admiring-knuth-vw1v8f`**。Render 会自动读到仓库里的 `render.yaml`，列出一个叫 `life-book` 的网站服务。
4. 它会要求填两个值：把第 1 步复制的 `UPSTASH_REDIS_REST_URL` 和 `UPSTASH_REDIS_REST_TOKEN` 分别粘进去。
5. 点 **Apply**（或 Deploy），等 3～5 分钟。状态变成 **Live** 就好了，页面上方会显示网址，类似 `https://life-book-xxxx.onrender.com`。

以后只要这个分支有新提交，Render 会自动重新部署。

## 3. 拿到管理密码

在 Render 里打开 `life-book` 服务 → 左侧 **Environment** → 找到 `ADMIN_TOKEN`（部署时自动生成的随机密码），点眼睛图标显示出来，复制。

**这个密码不要给任何人。**

## 4. 生成兑换码

1. 手机打开 `https://你的网址/admin`。
2. 把管理密码粘到第一栏。
3. 在"生成兑换码"里填数量（比如 20）和批次名，点**生成**。
4. 每行是一张卡密，格式是"网址 https://… 兑换码 XXXX-XXXX-XXXX"。点**复制全部**，粘到小红书店铺后台的卡密里。
   - **明文兑换码只显示这一次**，服务器只存加密后的摘要，记得马上复制。
5. 管理页还能**查询**某个码用了几台设备、帮换手机的买家**清空设备**、退款后**作废**，以及看**统计**。

## 5. 防止休眠（建议做）

1. 打开 cron-job.org，注册一个免费账号。
2. 新建一个任务（Create cronjob）：
   - 网址填 `https://你的网址/api/health`
   - 频率选**每 10 分钟**
3. 保存。这样网站会一直醒着，买家打开不用等。

Render 每个月给 750 个免费小时，一个网站一直开着正好够用（一个月最多 744 小时）。**不要再开第二个免费服务**，否则时长不够，网站会被暂停到下个月。

## 6. 测大陆能不能打开（一定要做）

1. 关掉 VPN，用手机流量打开你的网址，从头玩到兑换一次。
2. 打开 itdog.cn，选"网站测速"，输入你的网址，看全国各地、各运营商的结果：
   - 大部分地区绿色、几秒内打开：可以先用着。
   - 很多地区红色或超时：这个域名在大陆不好用。可以在 Render 里给服务绑一个自己的域名再测；还是不行，就换香港服务器（`docs/deploy.md`）。

## 7. 改店铺信息

打开仓库里的 `life-game/src/config.ts`（手机上可以用 GitHub 网页直接编辑），改：

- `where`：玩家去哪里买兑换码
- `price`：价格
- `site`：网址可以不填，分享图上会自动印当前网站的域名

保存提交后，Render 会自动重新部署。

## 出问题时

| 现象 | 处理 |
|---|---|
| Render 部署失败 | 打开服务的 **Logs**，把最后几十行截图发给我 |
| 网页能开，兑换总是失败 | 检查 Environment 里两个 Upstash 的值有没有多复制空格；去 Upstash 控制台看看有没有请求进来 |
| 管理页提示"管理密码不对" | 重新到 Environment 复制 `ADMIN_TOKEN`；连续输错 8 次会被暂停 15 分钟 |
| 第一次打开要等很久 | 正常，免费实例在休眠；做第 5 步就好了 |
