# 《二十四时》封面插画需求

你好！这是一个手机网页小游戏《二十四时》。玩家打开网页，第一眼看到的就是**封面**，所以这张图很重要：它要让路人在 3 秒内想点进去。需要你生成 **1 张竖版封面插画**。

---

## 一、这是什么产品（一句话）

玩家填入出生信息后，走进一本"书"，用 24 个选择把一生放进一天：从清晨出生，走到第二天破晓。读完会得到一张"人生签"和一份写给自己的《人生说明书》。气质：**安静、怀旧、温暖、东方，有一点点神秘，但不是算命摊的那种**。

## 二、交付规格

| 项目 | 要求 |
|---|---|
| 数量 | 1 张（想多出几个备选的话，最多 3 张，文件名后面加 `-a`、`-b`、`-c`） |
| 比例和尺寸 | 竖版 **1:2**，**1080×2160** 像素（手机全屏封面，会按"填满裁切"显示，四边可能被裁掉一点） |
| 格式 | JPG，质量 85 左右，**≤ 1.2MB** |
| 文件名 | `cover.jpg` |
| 存放位置 | 仓库里的 `life-game/art/cover-src/cover.jpg` |

## 三、构图要求（很重要，因为代码会在上面叠内容）

把画面从上到下分成三块：

| 位置 | 内容 |
|---|---|
| **上方约 55%** | **主画面**。这里是视觉焦点，画得最精细 |
| **右上角**（宽 25%、高 40% 的区域） | 代码会盖一块**竖排的书名签**，这里不要放重要图案，画面保持淡、平静 |
| **下方约 45%** | 要**逐渐变深、变安静**（深黛青色到近黑），代码会在这里放文字和按钮。**不要在这里画复杂图案，也不要有亮的色块** |
| **左侧约 8%** | 线装书的订线（代码画），不要放重要内容 |

最终效果就像一本**深色布面线装书**的封面，上半部分有一幅嵌进去的画。

## 四、画面内容（三选一，推荐 A）

**A（推荐）｜月洞窗与风铃**：深色老屋里的一扇圆形月洞窗，窗外是淡紫粉色的破晓天空和远处层叠的黛瓦屋顶；窗边挂着一串铜色旧风铃，一缕朱砂红的穗子垂下来；窗台下隐约有木摇篮的一角。整个画面的亮部集中在月洞窗里，窗外的光很柔和。

**B｜雨巷红伞**：徽派小巷，青石板雨后发亮，屋檐下一盏朱红灯笼；一个背着红书包的孩子撑着红伞的背影，走向巷子深处，远处有淡淡的晨光。

**C｜一碗面与万家灯火**：深夜的窗边，木桌上一碗冒着淡淡热气的番茄鸡蛋面，窗外是安静小城的万家灯火和一轮月亮；窗边挂着旧风铃。

## 五、统一画风

**风格关键词**：新中式水墨淡彩插画，徽派白墙黛瓦的中国南方小城，2000 年代的日常生活，**宣纸纹理**，安静、怀旧、温暖、有人间烟火气。

**配色**：整体偏**深**，以深黛青、藏蓝为底色，亮部是暖黄、淡粉紫；**朱砂红只做点缀**（风铃的红穗子、灯笼、红伞这种小面积）。饱和度偏低，不要高饱和、不要霓虹。

**必须遵守**：
1. **不画任何文字**：没有招牌字、没有印章字、没有水印、没有签名。书名由代码叠上去。
2. **人物不露正脸**：只画背影、远景小人或者手；看不出性别。
3. **不出现**：现代品牌和商标、手机屏幕、宗教符号、算命和占卜道具（罗盘、签筒、八卦图、符咒都不要）。
4. 整体要**像一本书的封面**，不是海报，也不是游戏截图。

## 七、交付前自查

- [ ] 1080×2160，JPG，≤ 1.2MB，文件名 `cover.jpg`。
- [ ] 上方 55% 是主画面，**下方 45% 是安静的深色**，没有复杂图案。
- [ ] 右上角 25%×40% 的区域没有重要图案。
- [ ] 没有任何文字和水印，没有正脸。
- [ ] 和已有的 28 张场景插画放在一起，是同一种笔触、同一种纸感。
- [ ] 确认你用的生图工具允许把生成的图用在收费产品里。

## 八、放进项目

1. 把 `cover.jpg` 放进 `life-game/art/cover-src/`。
2. 在 `life-game` 目录运行 `python3 scripts/optimize-scenes.py`（需要 `pip install pillow`），它会生成网页用的 `public/cover.webp`。
3. 运行 `npm ci && npm test && npm run build` 确认能构建，然后提交推送到 `claude/admiring-knuth-vw1v8f` 分支。

没有 `cover.webp` 时，封面自动保持现在的深色布面样式，不会出错。如果你不能改仓库，把图发给我就行。谢谢！
