# 向汉考国际申请词表/名称使用许可：材料清单与邮件草稿

> 这是**你**要做的一步，申请人必须是你本人。下面只是草稿，请按实际情况修改后再发。
> 没有任何一方的回复属于"默认同意"；只有书面答复才算数。

## 一、发信前先做三件事

1. **在 chinesetest.cn 找官方联系方式。** 看导航栏的"合作伙伴""研究者"子菜单，以及页面底部的
   "联系我们""法律声明"。记下官方邮箱、电话、在线表单（不要用来路不明的邮箱）。
2. **查"HSK"商标归谁。** 在国家知识产权局商标局的"商标网上查询"里搜 `HSK`、`汉语水平考试`，
   看注册人和类别（第 9 类软件、第 41 类教育培训）。这决定了该问谁。查询结果截图保存。
3. **想清楚你到底要什么**（越具体越容易得到答复）：
   - 能否在商业 App 中使用大纲词表（词语及其等级归属）？
   - 能否在副标题、关键词里描述性使用"HSK"字样？
   - 是否有面向个人开发者的合作或授权渠道？费用和期限？

您好！

想向贵方咨询以下问题：

1. 是否允许在商业 App 中使用大纲中的词表（词语及其所属等级）？如需授权，申请流程、费用和期限是什么？
2. 是否允许在 App 的副标题、说明和关键词中以描述性方式使用"HSK"字样（例如"备考 HSK 3.0 词汇"）？是否有品牌使用规范？

   - 不使用任何官方标识（Logo）；

   - 在应用内注明"HSK 是其权利人的商标，本应用与汉考国际无关联"。
4. 个人开发者是否有合作渠道？如果必须通过出版社或培训机构合作，能否推荐流程？

期待您的回复，谢谢！
