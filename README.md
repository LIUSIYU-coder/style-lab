# HSK Prep（暂定名）

面向外国学习者的 **新版 HSK 3.0 备考 App**（Expo / React Native，TypeScript）。

当前状态：**原型**。只有间隔复习核心 + 一个用示例词跑的闪卡界面，还不是可上架的产品。

## 在 iPhone 上试用（不需要 Mac）

1. 电脑装好 Node.js，在本目录运行 `npm install`
2. `npx expo start`
3. iPhone 装 **Expo Go**，扫终端里的二维码（手机和电脑在同一个 Wi-Fi）

## 开发命令

| 命令 | 作用 |
|---|---|
| `npm test` | 运行核心逻辑测试（`src/core/*.test.ts`） |
| `npm run typecheck` | TypeScript 类型检查 |
| `npx expo export --platform ios` | 验证 iOS 能否打包（不需要设备） |

## 代码结构

- `src/core/srs.ts`：间隔复习调度（SM-2 变体），纯函数
- `src/core/session.ts`：每次学习队列（到期复习优先，再补当天新词额度）
- `src/core/wordlist.ts`：词表数据结构和校验（查重、等级范围、拼音格式）
- `data/fixtures/sample-words.json`：**仅供开发的示例词，不是官方 HSK 词表**
- `App.tsx`：原型界面（进度只存在内存里）

词表通过 `Word` 结构加载，换词表来源不需要改调度逻辑。

## 重要决定和依据

- **只做 HSK 3.0。** 据汉考国际相关信息，HSK 3.0 计划于 2026-12-13 起全球正式开考，之后 2.0 不再并行。
  这个日期目前是由用户提供、并有第三方（某孔子学院页面）佐证，**尚未在汉考国际原文核对**。
- 竞品调研（美区 App Store，2026-10）：HSK 专项 App 最高仅约 1,000 条评分，针对 3.0 的 App 几乎空白；
  竞品差评集中在强制订阅、词表过时、发音错误、广告遮挡、多音字语音读错。

## 上架前必须解决（关卡）

1. **词表授权。** 官方词表/大纲的版权归属和商用许可没有确认。网上 GitHub 词表的 MIT 许可只覆盖整理者的工作，
   不等于出题方授权。需联系汉考国际或咨询知识产权律师。授权确认前，**不要把官方 PDF 提交进仓库**。
2. **以官方文件为准核对词表数量。** 第三方资料对 3.0 各级词汇量说法不一
   （如 300/500/1000/2000/3600/5400 与另一组数字冲突）。
3. **词典释义**如使用 CC-CEDICT：需署名、衍生数据按 CC BY-SA 公开，版本（3.0/4.0）要看下载文件头确认。
4. **发音**：多音字不能用系统语音直接读，需要按拼音校正或使用录音。
5. **Apple 开发者账号（99 美元/年）**：以上确认后再购买。
